# Pastebin interface

The editor is the primary action. Instance settings sit beside it on wide screens and below it on narrow screens. Results appear after publication. Opening a shared download or listing shows the recipient action without the publishing form.

Use the local system font for controls and monospace for keys, CIDs and byte counts. The warm canvas, white surfaces and blue actions are defined in `styles.css`; status messages use text as well as color. Keep long keys selectable and let tables scroll within their panel.

Use native radios, buttons, links and disclosures. Links navigate to independent content origins. A button performs an action such as fetching an anonymous S3 download or checking access. Keep keyboard focus visible, announce asynchronous status, and respect reduced motion. No external fonts, icons or scripts are needed.
