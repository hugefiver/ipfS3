## Complete versus abort overlap

The multipart race test held a bucket `FOR NO KEY UPDATE` gate. This permits the action insertion's foreign-key key-share lock while conflicting with the worker's bucket lock. The test observed the action as `claimed`, dispatched Complete while the gate was held, rechecked the claim, and released the gate before evaluating the terminal result.

Lifecycle abort won: Complete returned `NoSuchUpload`, GET returned `NoSuchKey`, ListObjectVersions contained neither an object version nor a delete marker, and the upload was absent. The durable action reached `succeeded`. This run proves the abort-winning branch, not that both winners were observed.
