# 远端 pin 的生命周期

S3 请求按文件版本管理 pin。对象发布、标签和 pin 需求在同一事务里提交；上传响应不等待备份服务。`pin_refs` 保存文件对远端内容的需求和到期时间。使用 `content=decompressed` 发布 ZIP 时，每个成功解压的文件版本持有指向自身 CID 的手动引用。删除归档不会释放这些引用；删除某个解压版本只释放该版本的引用。

`pin_resources` 按 `(provider, canonical CID)` 共享远端 pin。同一服务上的多份文件引用只占一份配额。worker 在数据库事务外调用服务，收到成功回执后写入 `accepted` 并保存返回的句柄。若上传结果未知，不能靠重复上传来确认。

取消或到期只释放相应引用。最后一个引用结束后，worker 才清理已提交的远端资源；服务确认删除或报告目标已不存在，即记为 `cleaned` 并释放配额。网关不以副本复查或物理块回收作为完成条件，也不为此删除主存储中的 S3 对象。

续期、取消、按版本查询状态和数据库升级步骤见[远端 pin 运维说明](pinning-recovery.md)。
